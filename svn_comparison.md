# Git и SVN

1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка — это указатель на коммит. Она создаётся мгновенно и не копирует файлы. В SVN ветка — это копия каталога на сервере, поэтому она тяжелее и медленнее.

2. Можно ли в SVN сделать коммит без интернета?
Нет. SVN централизованный: коммит сразу отправляется на сервер. Без сети можно только править файлы локально. В Git коммит пишется в локальную историю и сеть не нужна.

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
В старых корпоративных и государственных системах, где репозиторий уже на SVN, нужны права на отдельные каталоги и скачивание только части большого монорепозитория. Новые проекты начинают на Git.
