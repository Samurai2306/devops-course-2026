# Git в VS Code и в терминале

Удобно в VS Code:
1. В Source Control сразу виден diff каждого файла.
2. История коммитов и ветки показаны графически.
3. Конфликт можно закрыть кнопками Accept Current / Incoming.

Удобнее в терминале:
1. rebase, cherry-pick и push в несколько remote — на сервере есть только терминал.
