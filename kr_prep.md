# Подготовка к контрольной

## Когда rebase, а когда merge?
Rebase выбираю на своей ветке, которую ещё никто не тянет: история становится линейной. Merge выбираю для main и любой общей ветки: он не переписывает уже существующие коммиты.

## Что будет, если сделать rebase публичной ветки?
Хеши коммитов изменятся. У коллег останется старая история, push без force не пройдёт, а force-push сломает их ветки.

## Зачем нужен multi-remote?
Один код кладут в несколько мест: основной репозиторий команды и зеркало для бэкапа, либо GitHub для разработки и второй хостинг для заказчика. Push можно отправлять в оба remote одной командой.
